# DevOps Eng Proj

A minimal Java 25 project built with Maven.

## See the output

[Open the project output in your browser](https://shivangikanamas.github.io/Devops-Project/).

The Java program prints `Hello, Maven!` to the console.

## Build and test

```powershell
mvn test
```

## Run

```powershell
mvn package
java -cp target/classes com.example.Main
```
